# Export des échanges IA

Ce dossier reçoit l'export des conversations avec les assistants IA utilisés
pour cet exercice, conformément à l'énoncé (« IA : usage encouragé,
transparence exigée »).

À déposer ici : `exo2-conversations.txt` (ou les fichiers d'export natifs de
l'outil).

Avant de joindre l'export, le relire et caviarder ce qui n'a pas à y figurer :
clés d'API, mots de passe, secrets, et tout passage sans rapport avec
l'exercice. L'énoncé précise qu'un passage coupé n'est jamais pénalisé — un
secret laissé en clair l'est.
